# pyroelectric
Interface for the calculation of primary pyroelectric coefficients using Density Functional Theory and Self-Consistent Phonon Theory.

The details about the interface will be published in: S. Zeitz, K. Eklund, A. J. Karttunen, Pyroelectric properties of rhombohedral, orthorhombic, and tetragonal \ce{BaTiO3} investigated with density functional theory (submitted for publication).
