# pyroelectric
Interface for the calculation of primary pyroelectric coefficients using Density Functional Theory (DFT) and Self-Consistent Phonon Theory (SCPH).

The details about the interface will be published in: S. Zeitz, K. Eklund, A. J. Karttunen, Pyroelectric properties of rhombohedral, orthorhombic, and tetragonal BaTiO<sub>3</sub> investigated with density functional theory (submitted for publication).
